# Career OS — Web Dashboard

The Vite + React + TypeScript + Tailwind frontend for the Career OS web
dashboard (Phase 7). See the main repo's [README.md](../README.md) under
"Web dashboard (Phase 7)" for setup, the API it talks to
(`job_agent.web`), and what's implemented.

```bash
npm install
npm run dev     # http://localhost:5173, proxies /api to `job-agent serve` on :8000
npm run build   # writes dist/, which `job-agent serve` then serves directly
```
